**ProjectAddin Installation and User Guide**

**1. Add-in Installation**

1\) Exit Project before installation.

2\) Extract the **ProjectAddin.zip** package, which contains setup.exe,
template files, and other supporting files. Double-click **setup.exe**
to start the installation.

3\) An internet connection is required during installation, as the
installer needs to access the Microsoft website to download Microsoft
.NET Framework and Visual Studio 2010 Tools for Office Runtime. If these
components are already installed on your system, this step will be
skipped automatically.

4\) After installation, launch Project and open a file. An additional
**Addin** Ribbon tab will appear on the main menu.

5\) The main functions of these Add-ins are as follows:

a.  Quickly set background color for tasks by outline level

b.  Set uniform bar styles by task category

c.  Split tasks accurately based on a specified date

d.  Batch assign resources to tasks via notes text

e.  Organize Resources in a Tree Structure for Task Assignment

f.  Calculate the Derived resource Units based on the task\'s assigned
    resource

g.  Export tasks and resource data from Project to Excel

h.  A Solution for Tracking and Logging Task Completion Status

i.  How to Keep Tasks Starting on the 1st When the Project Schedule Is
    Adjusted

**2. Template Files**

The four features (b, e, h, i) require template files to function
properly. The template files predefine custom columns, views, Gantt
chart styles, calendars, and other settings necessary for the add-ins to
run.

You can delete the tasks and resources in a template file, save it as a
new file, and then insert your existing Project file for use. For
instructions, refer to the Help section in the Ribbon.

**3. Important Notes**

This add-in package is offered as a free trial with 90 total uses across
all features. Once the trial limit is reached, a license must be
purchased to continue using the software.

Please feel free to report any issues encountered during the trial. Your
feedback will be addressed promptly.
